# 实现 CircleChase 回环追踪轨迹

配置为 `Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动。

这组参数依次表示：

- `CircleChase`：轨迹类型。
- `3000`：总时长，单位为毫秒。
- `5`：外圈半径，单位为格（1 格 = 64 像素）。
- `2`：内圈半径，单位为格（1 格 = 64 像素）。

请阅读仓库中的代码，补齐 CircleChase 轨迹，使其满足以下行为：

- 子弹向目标飞行，并在目标周围形成回环轨迹。
- `Speed` 的单位是像素/秒；每帧三维位移等于 `Speed * dt / 1000`，Z 轴计入同一速度预算。
- 抵达节奏由 `totalTime` 决定，不应尽快命中；剩余速度应形成切向运动。
- 总时间耗尽后取消回环的时间调度，仍以固定 `Speed` 逐帧追踪当前目标；转向继续受角速度限制，目标移到身后时应在后续帧逐渐转向目标。
- 转向角速度上限为 `Speed` 度/秒；在环带内为 `Speed / 6`。
- 没有目标时沿当前朝向直线飞行，并且仍应成功启动、持续更新且不崩溃。
- 服务端和客户端在相同输入下应产生一致的三维轨迹。
- 子弹不会因命中目标而停止或销毁，飞行期间应始终保持速度守恒。
