# 实现 CircleChase 回环追踪

配置为 `Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动，请让它恢复正常飞行。

## 策划描述

希望有一种会“绕着目标接近”的子弹：目标较远时直接追上去；进入大圆 `R` 后，不要立刻撞向目标，而是边接近边绕行；进入小圆 `r` 后继续收拢追踪，直到完成这一轮追踪。整个过程应保持飞行速度，目标移动时也要持续修正方向。

## 程序规则

- 参数依次为轨迹类型、总时长（毫秒）、外圈半径（格）、内圈半径（格）；1 格 = 64 像素。
- 阶段判断使用子弹到目标的三维距离 `d`，不是仅计算 `XY` 距离。
- `d > R` 时直接向目标逼近。
- `r < d <= R` 时，按剩余时间在 `totalTime` 内完成径向接近，未用于径向接近的速度形成切向运动，从而产生回环。
- `d <= r` 时仍然追踪目标并继续收拢，不锁定为当前朝向直线飞行。
- 每帧三维位移长度必须为 `Speed * dt / 1000`，Z 位移计入同一速度预算。
- 转向角速度上限为 `Speed` 度/秒；在环带 `r < d <= R` 内为 `Speed / 6` 度/秒。每帧转角不得超过 `角速度 * dt / 1000`。
- 总时间耗尽后取消时间调度，以固定 `Speed` 继续追踪当前目标；目标转到身后时必须受限逐渐掉头。
- 没有目标时沿当前朝向直线飞行；启动和更新必须安全，不得崩溃或销毁子弹。
- 服务端和客户端使用同一套转向规则、角度约定和三维速度分配。相同输入必须产生逐帧一致的三维坐标。
- 客户端可能延迟收到目标快照，只能根据本地最新快照追踪，不得瞬移；延迟只作为展示场景，不要求修改网络同步链路。
- 子弹全程保持速度，不因接近或穿过目标而停止或销毁。
