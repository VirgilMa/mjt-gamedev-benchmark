# 实现 CircleChase

`Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动。

实现一种围绕目标重复命中的子弹：追踪并穿过目标，离开后沿饱满圆弧回环，再次命中。目标移动时也应持续跟随。

实现方式不限，不要求与参考答案一致，以实际圆弧回环效果为准。

参数依次为轨迹类型、时间（毫秒）、外圈半径 `R`、内圈半径 `r`；半径单位为格，`1` 格等于 `64px`。

- 目标 XY 距离不超过 `32px` 视为命中；默认 `600` 帧内至少命中 `5` 次，且应持续回环命中。
- 回环应连续、饱满，不总在同一侧，也不沿原路折返。
- `R` 和 `r` 都应影响回环形态，增大 `R` 应产生更大的回环。
- 同一场景下，客户端与服务端子弹的逐帧距离必须小于 `64px`。

仅修改 `real/` 下的实现代码并保留其他轨迹行为。可运行 `lua trajectory_runner.lua server moving` 或 `lua trajectory_runner.lua client moving` 输出逐帧 CSV 轨迹。
