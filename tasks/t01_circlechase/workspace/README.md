# 实现 CircleChase 回环追踪

配置为 `Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动，请补齐其轨迹逻辑。

参数依次为：轨迹类型、总时长（毫秒）、外圈半径（格）、内圈半径（格）。1 格 = 64 像素。

## 行为要求

- 子弹应追踪目标，并在目标周围形成回环轨迹。
- `Speed` 单位为像素/秒；每帧三维位移长度必须为 `Speed * dt / 1000`，Z 位移计入同一速度预算。
- `d > r1` 时直接逼近目标；`r2 < d <= r1` 时按剩余时间 `totalTime` 分配径向速度，余速用于切向运动；`d <= r2` 时继续收拢追踪，不得停止。
- 总时间耗尽后取消时间调度，以固定 `Speed` 继续追踪当前目标；目标转到身后时必须受限逐渐掉头。
- 转向角速度上限为 `Speed` 度/秒；在 `r2 < d <= r1` 的环带内为 `Speed / 6` 度/秒。每帧转角不得超过 `角速度 * dt / 1000`。
- 没有目标时沿当前朝向直线飞行；启动和更新都必须安全，不得崩溃或销毁子弹。
- 服务端和客户端使用同一套转向规则、角度约定和三维速度分配。相同目标快照、位置、朝向和 `dt` 必须产生逐帧一致的三维坐标。
- 客户端可能延迟收到目标快照，只能根据本地最新快照追踪，不得瞬移。延迟只作为展示场景，不要求修改网络同步链路。
- 子弹全程保持速度，不因接近或穿过目标而停止或销毁。

请自行阅读代码并选择实现方式。
