# 实现 CircleChase

`Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动。

实现一种围绕目标重复命中的子弹：追踪并穿过目标，离开后沿饱满圆弧回环，再次命中。目标移动时也应持续跟随。

实现方式不限，不要求与参考答案一致，以实际圆弧回环效果为准。

三个数值参数的含义：

- `3000`（`totalTime`）：从一次命中到再次命中的期望回环周期，单位为毫秒。
- `5`（`R`）：回环的外侧尺度，控制子弹离开目标后回环的大小。
- `2`（`r`）：回环的内侧尺度，控制子弹穿过目标后保持向前、再进入弧线回转的距离。

`R` 和 `r` 的单位为格，`1` 格等于 `64px`，并且应满足 `0 < r < R`。命中判定仍为子弹与目标的 XY 距离不超过 `32px`，与 `r` 不是同一概念。

- 目标 XY 距离不超过 `32px` 视为命中；默认 `600` 帧内至少命中 `5` 次，且应持续回环命中。
- 回环应连续、饱满，不总在同一侧，也不沿原路折返。
- `R` 和 `r` 都应影响回环形态，增大 `R` 应产生更大的回环。
- 移动目标场景中，客户端使用延迟 `4` 帧的目标位置快照。客户端与服务端子弹轨迹应产生实际差异，但逐帧距离的最大值必须小于 `64px`。

仅修改 `real/` 下的实现代码并保留其他轨迹行为。不得修改 `trajectory_runner.lua`、`runtime.lua` 和 `stubs/`下的文件，否则完整性检查直接判为 `0` 分。

可运行 `lua trajectory_runner.lua server moving` 或 `lua trajectory_runner.lua client moving` 输出逐帧 CSV 轨迹。
