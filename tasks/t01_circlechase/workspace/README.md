# 实现 CircleChase 子弹

配置为 `Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动，请让它恢复正常。

## 策划意图

我们希望有一种**围绕目标重复命中**的子弹：子弹追踪目标，穿过目标完成一次命中；命中后继续向前飞，离开目标一段距离，再沿回环轨迹返回并再次命中。这个过程持续重复，而不是命中一次就停止。

目标可以移动，子弹应持续跟随。回环不应总在同一侧、沿同一个方向重复；策划需要能够通过半径参数控制回环的大小。
