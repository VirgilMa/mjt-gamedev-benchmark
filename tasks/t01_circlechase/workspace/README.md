# 实现 CircleChase 子弹

配置为 `Trajectory = "CircleChase, 3000, 5, 2"` 的子弹当前完全不动，请让它恢复正常。

## 策划目标

我们希望有一种会围绕目标接近的子弹：目标距离较远时，子弹向目标飞行；接近目标后，子弹不应直接撞上去，而应在目标周围形成有弧度的回环或螺旋轨迹；进入更近的范围后，继续围绕并逐渐接近目标。

目标可以移动，子弹应持续追踪目标并保持自然、连续的飞行。服务端和客户端都应表现出一致的轨迹行为。

请自行阅读代码，理解现有轨迹系统，并完成这一种子弹模式的实现。实现过程中保留现有系统的正常行为，只修改实现代码，不修改环境桩、运行时或评测设施。

题目维护者会运行服务端和客户端轨迹，并提供 HTML 页面展示轨迹结果；不需要创建或修改展示页面。完成后保留代码修改，并在最终回复中简要说明修改内容。
