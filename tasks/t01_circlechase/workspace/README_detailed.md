# CircleChase 详细设计

## 参数

`Trajectory = "CircleChase, totalTime, R, r"`

- `totalTime`：一轮追踪周期的时长，单位为毫秒。
- `R`：回环外半径，单位为格；1 格 = 64 像素。它控制子弹离开目标后回环的最大尺度。
- `r`：目标附近的命中半径，单位为格；1 格 = 64 像素。它定义一次穿过目标和下一次命中的范围。
- 参数应满足 `0 < r < R`。

## 运动过程

1. 子弹与目标距离大于 `R` 时，直接追踪目标。
2. 子弹进入 `r` 范围时，记为一次逻辑命中，但不得停止、销毁或改变速度。
3. 命中后继续穿过目标并向前运动，逐渐离开目标；轨迹的外缘不应超过由 `R` 控制的回环尺度。
4. 到达回环外侧后，子弹沿弧线转向目标并返回；再次进入 `r` 范围时完成下一次命中，然后开始下一轮。
5. 目标移动时，回环的中心应跟随目标当前位置，而不是围绕旧位置完成整圈。

## 回环方向

每次命中后应优先切换到上一次回环的相反侧，减少连续沿同一方向绕行。左右方向的切换必须通过连续转向完成，不能瞬间反向或瞬移；如果目标移动导致理想方向不可用，应选择最接近相反侧的可行方向。

## 通用运动约束

- `Speed` 单位为像素/秒；每帧三维位移长度为 `Speed * dt / 1000`，Z 位移计入同一速度预算。
- 朝向必须连续变化，单帧转角受角速度上限约束；不得为了命中瞬间改变朝向。
- 没有目标时沿当前朝向继续飞行，启动和更新都必须安全。
- 服务端和客户端使用相同的轨迹数学；相同目标快照、位置、朝向和 `dt` 必须产生一致轨迹。客户端目标快照延迟时，只能基于本地最新快照追踪，不得瞬移。
- 命中不是终点，子弹应持续执行后续回环并保持飞行。
